# Goosic 0.4.5

Your desktop, just as you left it.

## A shortcut only when you ask

Delete it once. It stays gone.

Windows Setup used to remember your original desktop shortcut choice and could bring the
shortcut back on an update. The shortcut now requires a fresh opt-in. If you already have a
shortcut on your desktop, the update leaves it in place.

## Downloads and installation

Installed Windows copies can update through Goosic. The x64 installer and portable ZIP are
also available below. Extract the portable ZIP before launching. The installer is unsigned.
If SmartScreen intervenes, choose More info, then Run anyway.

The universal macOS alpha ZIP supports Apple silicon and Intel Macs. Move Goosic to
Applications. The app is signed ad hoc. If macOS refuses the first launch, use System Settings
→ Privacy & Security → Open Anyway.

SHA-256 checksums accompany the Windows and macOS downloads.
