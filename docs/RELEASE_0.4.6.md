# Goosic 0.4.6

Pick your pace.

## Stable or experimental

Choose how new you want Goosic.

Settings now has an update channel on macOS and Windows. Stable, the default, offers tested
releases only, exactly as before. Experimental also offers pre-releases, with new features
before they settle. Choose it, and the next experimental build arrives through the usual update
prompt. Switching back to stable never downgrades: Goosic keeps what it has until a stable
release passes it.

This release changes nothing else. On Windows the channel is under Settings → Updates; on the
Mac, under Settings → General → Updates.

## Downloads and installation

Installed Windows copies can update through Goosic, and Macs through Goosic → Check for
Updates. The x64 installer and portable ZIP are also available below. Extract the portable ZIP
before launching. The installer is unsigned. If SmartScreen intervenes, choose More info, then
Run anyway.

The universal macOS alpha ZIP supports Apple silicon and Intel Macs. Move Goosic to
Applications. The app is signed ad hoc. If macOS refuses the first launch, use System Settings
→ Privacy & Security → Open Anyway.

SHA-256 checksums accompany the Windows and macOS downloads.
