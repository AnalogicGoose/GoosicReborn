# Goosic 0.4.1

Lyrics that move with the music.

## Windows: follow every phrase

The words arrive in time.

Word-timed lyrics now brighten as they are sung. Each line follows on its own spring,
while quiet passages show three interlude dots. Pause the music and the cover settles
smaller. Songs with line timing keep their whole-line highlight. Word timing depends
on what the lyrics provider supplies.

## macOS: a gentler rhythm

Room for every word, and every pause.

Lyrics follow with a short delay between rows. Supplied line endings let finished
phrases settle into rest, and longer marked gaps show interlude dots. Word sweeps,
held-word emphasis and the paused cover complete the listening view. The macOS download
remains an alpha.

## Native on each desktop

One listening experience, shaped for each system.

Windows uses character fill instead of a soft gradient and does not lift, swell or glow
individual words. Its backdrop already includes a dark veil. Linux retains whole-line
lyrics; its fixtures now accept the optional line end without inventing timing.

## What still needs a live check

Compilation is only the beginning.

Windows lyrics visuals have not been checked live. Inspect line changes for a possible
one-frame flash, then check pauses, seeks, manual scrolling, wrapped text and accessibility
settings. The latest macOS per-row motion also awaits owner acceptance. Tests and builds
do not establish live singing alignment.

## Downloads and installation

Windows offers an x64 installer and portable ZIP. Extract the portable archive before
launching. The installer is unsigned; if SmartScreen intervenes, choose More info, then
Run anyway. SHA-256 checksums accompany the downloads.

The universal macOS ZIP supports Apple silicon and Intel Macs. Move Goosic to Applications.
The app is signed ad hoc; after the first refused launch, use System Settings → Privacy &
Security → Open Anyway. SHA-256 checksums accompany the Mac download.

This release is prepared as an unpublished draft for owner inspection. The owner must sign
and update the Sparkle feed before installed Macs can discover it. Linux has no release
download in this version.
